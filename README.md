# 静角

一个用来安静下来的小工具。不是效率工具，是反效率的——它的全部功能就是让你慢下来三分钟。

## 它能做什么

| 模式 | 说明 |
|---|---|
| 🫁 呼吸引导 | 4-4-6-2 呼吸节律（吸-停-呼-停），动画引导 |
| 🍃 放下烦心事 | 把烦心事写下来，看它慢慢飘散消失 |
| 🧘 静坐计时 | 3 / 5 / 10 分钟静坐，结束时一声钟 |

## 使用

用浏览器直接打开 `index.html` 即可，纯单文件，无任何外部依赖，不需要联网。
